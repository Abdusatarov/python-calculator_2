# 🧮 PyQt5 Calculator

Небольшой, но стильный учебный проект на Python — настольный калькулятор с графическим интерфейсом, разработанный с использованием **PyQt5**.

## ✨ Особенности

- Классический интерфейс калькулятора  
- Крупные и удобные кнопки  
- Контрастная современная тема  
- Поддержка:
  - базовых операций (`+`, `-`, `×`, `÷`)
  - процента (`%`)
  - десятичной точки (`.`)
  - удаления символа (Backspace)
- Автоматическое вычисление выражения  
- Простая и понятная логика обработки ввода  

## 🛠️ Технологии

- Python 3  
- PyQt5  
- Qt Designer
